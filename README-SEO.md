# Paket SEO MH Tour - GitHub Pages

Target website:
https://denmur1.github.io/MH-Tour-Web/

## Isi paket
- `index.html` — halaman utama dengan title, meta description, canonical, Open Graph, Twitter Card, dan Schema.org JSON-LD.
- `robots.txt` — mengizinkan crawler dan menunjuk sitemap.
- `sitemap.xml` — sitemap untuk URL utama GitHub Pages.
- `site.webmanifest` — metadata web app.

## Cara memasang
1. Buka repository `denmur1/MH-Tour-Web` di GitHub.
2. Ganti `index.html` lama dengan `index.html` dari paket ini.
3. Upload `robots.txt`, `sitemap.xml`, dan `site.webmanifest` ke root repository.
4. Commit perubahan ke branch/folder yang digunakan GitHub Pages.
5. Tunggu GitHub Pages selesai publish.
6. Buka:
   https://denmur1.github.io/MH-Tour-Web/
   https://denmur1.github.io/MH-Tour-Web/robots.txt
   https://denmur1.github.io/MH-Tour-Web/sitemap.xml

## Google Search Console
Setelah file online:
1. Tambahkan property website ke Google Search Console.
2. Verifikasi kepemilikan.
3. Buka menu Sitemaps.
4. Kirim `sitemap.xml`.
5. Gunakan URL Inspection untuk URL utama dan pilih Request Indexing.

Catatan: sitemap membantu Google menemukan URL, tetapi tidak menjamin peringkat atau indexing instan.
